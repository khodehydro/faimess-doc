# Fiplan — Travel Planner Dashboard

بازسازیِ کدشدهٔ صفحهٔ Home از طراحی مرجع Fiplan (اسکن طراحی در [`docs/design-home-scan.md`](docs/design-home-scan.md)).
پروژه با **Vite + React 19 + TypeScript + Tailwind CSS v4 + Framer Motion** ساخته شده و همهٔ تصویرسازی‌ها (غروب، مپ، کمپینگ، آواتارها) **SVG داخلی** هستند — یعنی بدون هیچ درخواست تصویر خارجی و کاملاً آفلاین رندر می‌شود.

---

## اجرا روی سیستم لوکال

```bash
# ۱) نصب پکیج‌ها
npm install

# ۲) اجرای سرور توسعه
npm run dev
# → http://localhost:5173

# ۳) بیلد پروداکشن (اختیاری)
npm run build && npm run preview
```

> پورت پیش‌فرض `5173` است و سرور روی `0.0.0.0` گوش می‌دهد تا از داخل شبکه/پیش‌نمایش هم قابل دسترسی باشد.

## ساختار

```
src/
├── App.tsx                     قاب شناور + چیدمان دو ستونی + سیستم Toast
├── index.css                   توکن‌های دیزاین (رنگ/شعاع/سایه/فونت) + کی‌فریم‌های انیمیشن
├── lib/
│   ├── data.ts                 تمام محتوای صفحه (منو، سفر، رویدادها، مکالمه‌ها) — نقطهٔ تغییر متن‌ها
│   ├── motion.ts               واریانت‌های مشترک انیمیشن (rise / spring / ease)
│   └── cn.ts
├── hooks/useClickOutside.ts
└── components/
    ├── TopBar.tsx              لوگو، ناوبری کپسولی، جست‌وجو، اعلان‌ها، پروفایل
    ├── TripHero.tsx            کارت سفر فعال + مپ + پارالاکس ماوس
    ├── SchedulePanel.tsx       تقویم تایم‌گرید + چیپ‌های رویداد + کارت شناور قابل‌درگ
    ├── GreetingPanel.tsx       خوش‌آمد + «I want to...» + فیلترهای سریع
    ├── ChatPanel.tsx           لیست گفتگو + ترد پیام + کارت دعوت Accept/Reject
    ├── Scenes.tsx              همهٔ تصویرسازی‌های SVG (غروب، مپ، کمپینگ، بندانگشتی‌ها)
    ├── Avatar.tsx              آواتارهای تصویرسازی‌شده + آواتار-استک
    ├── Icon.tsx                ست آیکون خطی + لوگو
    └── ui.tsx                  کارت، دکمهٔ دایره‌ای، متادیتا
```

## انیمیشن‌ها و تعامل‌های پیاده‌شده

| بخش | تعامل |
|---|---|
| ورود صفحه | ورود پله‌ای قاب، کارت‌ها و المان‌ها (fade + rise) |
| ناوبری | پیل کورالِ آیتم فعال با `layoutId` بین آیتم‌ها سُر می‌خورد |
| جست‌وجو | فیلد با فوکوس پهن می‌شود + دراپ‌داون نتایج زندهٔ فیلترشده |
| اعلان‌ها / پروفایل | پنل‌های in-out با AnimatePresence + ذره‌بین/زنگ با انیمیشن hover |
| کارت سفر | پارالاکس ملایم تصویر با حرکت ماوس + دکمهٔ پوشهٔ تیره |
| تقویم | ستون روز فعال با `layoutId` جابه‌جا می‌شود؛ swبچ نما (تایم‌گرید/لیست)؛ استپر ماه |
| کارت شناور کمپینگ | **قابل درگ** با اسنپ و سایهٔ عمیق‌تر هنگام درگ |
| خوش‌آمد | تکان‌خوردن دست 👋، برگ‌های تزئینی متحرک، اسپارکل پس از ارسال درخواست |
| چت | تعویض مکالمه، Accept/Reject دعوت، ارسال پیام، ایندیکیتور تایپینگ، پاسخ خودکار، اسکرول خودکار |
| تصویرسازی‌ها | پرنده‌های در حال پرواز، پولک‌های آب، ستاره‌های چشمک‌زن، شعلهٔ آتش، سایه‌های موج‌دار |
| دسترس‌پذیری | احترام به `prefers-reduced-motion` (هم CSS و هم Framer Motion) |
